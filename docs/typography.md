# タイポグラフィと余白の規約

対象は Web リーダー（`web/www/style.css` と `web/app` の描画）。文字の設定はレイアウトの原則に従属させる。個々の要素に数値を書かず、`:root` のトークンを当てる。知見が増えたら変えるのはトークンの値かこの文書の文言で、要素ごとの個別調整は規約違反とみなす。`web/tests/e2e/typography.spec.js` が規約を検査する。

## 上位原則

- **近接**: 余白の大小で関係の強さを表す。部品の内側 4px、同じグループの要素間 8px、グループ間と左右ガター 16px、セクション間 24px。
- **8px グリッド**: バーや行の高さは 8 の倍数。内側の細部は 4 の倍数まで許す。
- **整列**: 同じ列の文字は左端を揃える。サイズが混在する行は `align-items: baseline`。行高をグリッドに乗せることで行ボックスの高さを揃える。

## トークン

| トークン | 値 | 使う場所 |
| --- | --- | --- |
| `--s-1` … `--s-4` | 4 / 8 / 16 / 24px | 余白。左右ガターは `--gutter-x`（デスクトップ 16、モバイル 8） |
| `--t-xs` / `--lh-xs` | 11 / 16px | caption、badge、ファイル名ラベル、ツリーアイコン |
| `--t-sm` / `--lh-sm` | 12 / 16px | ツリー、タブ、ボタン、メニュー |
| `--t-md` / `--lh-md` | 13 / 20px | 基準。入力、ダイアログ、pick |
| `--t-lg` / `--lh-lg` | 15 / 24px | 概観の要約文、ロゴ |
| `--t-xl` / `--lh-xl` | 24 / 32px（モバイル 20 / 24px） | 概観タイトル、空状態タイトル |
| `--t-touch` | 16px | タッチ端末の入力欄。iOS のフォーカス時ズームを避ける |
| `--code` / `--lh` | 初期 14 / 24px | エディター、差分、ピン留め。ズームで変わる |
| `--code-sm` / `--lh-code-sm` | 12 / 20px | UI 内のコード片。定義プレビュー、pointer、relations |
| `--control` / `--control-sm` | 28 / 24px | ボタンの高さ。32px のバー内は sm |
| `--w-strong` | 600 | 強調。700 はロゴだけ |
| `--ui` / `--mono` | system-ui 系 / ui-monospace 系 | どちらも和文フォールバック（Hiragino Sans、Yu Gothic UI）を持つ |

## ルール

1. **高さは 8 の倍数**。トップバー 48、タブ 40、パス 40、ナビ 32、ステータス 32、ツリー行 32。ツリー行の高さは `app/render.mbt` の `tree_row_height()` と一致させる。
2. **サイズと余白はトークンのみ**。コンポーネントの CSS に数値の font-size / line-height / padding / gap / margin を書かない。例外は `0`、`1px` の罫線、コード列の `ch` 単位、`calc()` で導いた値。
3. **コードの行高は 4px 丸め**。`line_height()` は `round(code × 1.6 ÷ 4) × 4`（14→24、12→20、16→24、18→28）。差分行とキャレットも同じ値を使う。
4. **ズームはコードだけに効く**。⌘+ / ⌘− はルートの `--code` と `--lh` を変える（`set_code_size`）。UI の文字と余白は動かない。
5. **書体は由来で選ぶ**。パス、行番号、型情報、差分はコード由来なので `--mono`。説明文、ボタン、メニューは `--ui`。
6. **イタリックを使わない**。和文フォントに斜体はなく合成斜体になる。コメントや引用は色で区別する。太字は 600 のみ。
7. **数字が並ぶ場所は `tabular-nums`**。caption（行・列の位置）、差分の行番号。
8. **タッチ端末の例外**。タップ領域 44px と入力欄 16px はプラットフォームの制約で、グリッドの外として明記する。
