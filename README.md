# Readit

AIが書いたコードを、人が理解するためのIDE。Rust / GPUIのmacOSネイティブアプリです。
ファイルツリー・タブ・編集を基本に、変更の比較、読む順番、引用付きの理解メモを加えています。

## 起動

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer cargo run -- --demo
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer cargo run -- /absolute/path/to/repository
```

Rust stable、Xcode、Gitが必要です。開発時はMetalシェーダーを実行時コンパイルします。
`python3 scripts/package_macos.py` で `artifacts/Readit.app` を更新できます。
これはアドホック署名のローカル開発版です。サンプルはこのリポジトリ内の `demo/` を参照します。

## ファイル・閲覧・編集

- フォルダ階層ツリー、空フォルダの表示、マウス／矢印キーで展開・移動。
- 複数タブ、×／中クリックで閉じる、閉じたタブの復元、タブ切替。編集中の内容・カーソル・Undo履歴をタブごとに保持。
- 本文の直接編集、複数行選択、コピー・切り取り・貼り付け、Undo/Redo、インデント。
- Tree-sitterによるPython、Rust、JS/TS、TSX、JSON、Markdown、HTML/CSS、Goなどの構文ハイライト。
- 行番号、カーソル位置、横・縦スクロール、折返し、文字サイズ変更。
- ネイティブダイアログでファイル／フォルダを開く。新規ファイル／フォルダ、保存、すべて保存、名前を付けて保存。
- ファイル／フォルダの名前変更・移動、削除、復元。右クリックメニューとmacOSメニューバーからも操作可能。
- 未保存のタブを閉じる・終了・プロジェクト切替・再読込の際に、保存／破棄／キャンセルを確認。
- 外部変更があるファイルへの保存・削除を拒否。既存パスへの新規保存・名前変更・復元では上書きしません。
- クイックオープン、プロジェクト内の文字列検索、ファイル内検索（大文字小文字・正規表現切替）、文字列置換、行:列への移動、移動履歴、コマンドパレット。

保存先と名前変更先は、開いているプロジェクト内の相対パスです。親フォルダは先に作成してください。
削除はOSのゴミ箱ではなく、プロジェクト内の `.readit/trash` に保管し、メニューから最後の削除を復元します。
フォルダ削除は中身もまとめて移動します。

## コードを辿る（0.3）

カーソルを識別子に置き、上部の「定義」「使用箇所」「シンボル」「型・説明」、
macOSの「移動」メニュー、または次のキーで解析を実行できます。

| 操作 | キー |
| --- | --- |
| 定義元へ移動 | F12 / ⌘クリック |
| 定義の周辺コードをプレビュー | ⌥F12 |
| 型定義へ移動 | ⌘F12 |
| インターフェースなどの実装へ移動 | ⇧⌘F12 |
| 使用箇所を検索（宣言を含む） | ⇧F12 |
| ファイル内の関数・クラス・変数一覧 | ⇧⌘O |
| 型・シグネチャ・ドキュメント | ⌘K → ⌘I |
| 元の位置へ戻る / 進む | Ctrl+- / Ctrl+Shift+-、本文上部の← / → |

定義が1件ならそのファイル・行・列へ直接移動します。複数候補や参照は、周辺コードの
プレビュー付き一覧から選べます。文字列で絞り込み、↑↓とEnterで移動できます。
移動後も下部の結果一覧を残すため、使用箇所を順に辿れます。×で閉じられます。
型情報は現在位置で明示的に表示します。マウスホバーによる自動表示は未対応です。

PythonはPyright、JavaScript/TypeScriptはTypeScript Language Server、Rustはrust-analyzerを利用します。
単語一致の代用ではなく、各サーバーのLSP解析結果を表示します。未保存の変更も同期します。
同名でも別スコープの変数を区別します。aliasや動的コードの参照範囲は各サーバーの意味解析に依存します。
型定義・実装検索など、サーバーが提供しない機能は未対応と表示します。
他言語の定義・参照解析はまだ対応していません。

解析中に内容・プロジェクトが変われば古い結果を破棄します。取得後に編集した場合も、
古い位置へジャンプせず再解析を案内します。標準ライブラリなどプロジェクト外の定義は閲覧専用タブで開きます。
外部定義はUTF-8の通常ファイル・1MiB以内に対応します。URIによるWebページの自動表示は行いません。
結果は最大2,000件です。行・列はLSPのUTF-16位置からエディタの文字位置へ変換します。

### 言語サーバーのセットアップ

この作業環境では設定済みです。別の環境ではNode.js 24以降とnpmを用意し、次を実行します。

```sh
python3 scripts/setup_lsp.py
# Rustを読む場合
rustup component add rust-analyzer
python3 scripts/setup_lsp.py
```

`tools/lsp/package-lock.json`でPyright 1.1.413、TypeScript Language Server 6.0.0、
TypeScript 5.9.3を固定しています。tsserver互換性のためTypeScript 7系は使用していません。
セットアップはReadit専用ディレクトリにnpm依存を導入し、ローカルの実行パスを
`tools/lsp/runtime.json`へ記録します。開いた対象プロジェクトには依存を追加しません。
`READIT_NODE`、`READIT_RUST_ANALYZER`環境変数でも実行ファイルを指定できます。
`.app`も現在はこのリポジトリ内の言語サーバーを参照するローカル開発版です。

解析はローカルの別プロセスで実行し、UIを待たせません。サーバーは初回利用時に起動します。
Rustのbuild script・proc macro・自動チェックは無効にしています。診断表示、補完、
シンボルrename、call hierarchy、language serverの設定UI・再起動コマンドは今後の対象です。

## 読むための機能

ファイル名による「背景・契約・実装・検証・設定」の仮の読む順番に切り替えられます。
本文でカーソルを置き、右側で疑問を入力して「コードと一緒に記録」すると、その行の引用とともに保存します。
「理解済み」の記録はコード全文に紐づき、内容が変わると未確認に戻ります。
GitルートではHEADと編集中の内容を比較し、通常フォルダでは読込時の内容と比較します。
差分の追加行をクリックすると本文の該当行へ戻れます。

記録は `.readit/session.json` に保存します。引用・理解済み時のコード本文を含むので、
対象リポジトリの `.gitignore` に `.readit/` を追加してください。
保存前の編集はメモリ内です。通常終了では確認しますが、クラッシュ時の自動復元は未実装です。

## 検証

```sh
cargo test --offline --lib
cargo test --offline --test language_services -- --ignored
python3 -m unittest discover -s demo/tests -p 'test_*.py'
```

ファイル・フォルダの作成／名前変更／削除／復元、上書き防止、外部変更、Git基準、引用記録、差分、ツリーをテストしています。
実画面でも直接編集、色分け、タブ操作、Undo/Redo、検索、保存、削除／復元を確認しています。
LSPの結合テストは実際の3言語サーバーを起動し、importの別名・スコープの区別・未保存編集・定義・参照・型・実装の解決を確認します。通常のテストでは未導入環境を考慮してignoreし、上記コマンドで明示実行します。

## 現段階の範囲

VSCode/Zedのすべての機能を再現したものではありません。
LSPの補完・診断、マルチカーソル、エディタ分割、ドラッグによるタブ移動、
自動フォーマット、ファイル監視、クラッシュ復旧、AI接続、統合ターミナル／実行環境は今後の対象です。
検索は読込済みファイル内を対象とし、プロジェクト検索は文字列一致・最大200件、クイックオープンは最大80件です。

読込時は最大400ファイル、1ファイル256KiB、UTF-8のみ。シンボリックリンク、バイナリ、
ビルド生成物、`.env*`、代表的lockfileを自動読込から除外します。明示的に開いたUTF-8ファイルは追加できます。
通常フォルダは深さ12まで、GitルートはGitのignoreを尊重します。大規模リポジトリへの最適化は未実施です。
差分はステージ済み／未ステージを分離せず、削除ファイル・renameの専用表示も未対応です。
改行コードのみ／末尾改行のみの変化は差分行に現れません。
コードをAIサービスには送信しません。解析用言語サーバーをローカルで起動しますが、対象のアプリ・テストは自動実行しません。
