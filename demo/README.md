# Checkout: 割引と送料の計算を理解する

これはReaditの操作を試すためのサンプルです。AIが実際に生成したコードではありません。

## 確認したい変更

割引後の商品合計が5,000円以上なら送料無料にする。
割引前の金額と取り違えていないか、境界値のテストから確かめます。

## 読む順番

1. src/contracts.py: 入力と出力の意味を読む
2. src/checkout.py: 計算と条件分岐を読む
3. tests/test_checkout.py: 4,999円／5,000円の境界を確かめる

## 小さな実験

checkout.py の `>= FREE_SHIPPING_THRESHOLD` を `>` に変えると何が起きる？
変更前に予測を疑問として記録し、中央のエディタで直接編集します。
「差分」で保存前の変化を確認し、⌘Zで元に戻すか、⌘Sでファイルに保存します。
保存後、ターミナルで `python3 -m unittest discover -s demo/tests -p 'test_*.py'` を実行します。
境界値テストが失敗することを確かめたら `>=` に戻してください。

Readitはこのコマンドを自動実行しません。
